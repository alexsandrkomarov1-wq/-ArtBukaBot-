# KOMAROVA_CORE

Публичная витрина семейного проекта KOMAROVA_CORE.

## Назначение

KOMAROVA_CORE — единое семейное информационное пространство для сохранения семейной истории, людей, связей, событий, документов и открытых публикаций.

Публичный сайт показывает только материалы, разрешённые для открытого доступа. Личные данные, контакты, документы, переписки и закрытые семейные сведения сюда не загружаются.

## Состав проекта

- **Публичная витрина** — сайт на GitHub Pages.
- **Основное ядро** — backend и единый реестр семейной информации.
- **Облачные подключения** — отдельные интеграции, подключаемые через защищённый backend.

Публичная витрина не является самим закрытым семейным кабинетом и не заменяет backend.

## Текущий статус

| Компонент | Состояние |
|---|---|
| Публичная витрина GitHub Pages | Начальная версия |
| Backend KOMAROVA_CORE | Разработка и подготовка развёртывания |
| Google Drive API | Включён в Google Cloud |
| Google Drive OAuth | Код и миграция подготовлены в отдельной ветке; интеграция ещё не развёрнута |
| OAuth Client ID | Не создан |
| Постоянный HTTPS-адрес backend | Ожидается размещение сервера |
| Реальная синхронизация с Google Drive | Ещё не запущена |

Текущий OAuth-код находится в ветке `feature/google-drive-oauth-foundation` и рассматривается через [PR №13](https://github.com/alexsandrkomarov1-wq/-ArtBukaBot-/pull/13). До проверки, объединения изменений, развёртывания backend и успешного теста нельзя считать подключение Google Drive действующим.

## Технологии публичной витрины

- Jekyll
- Markdown и Liquid
- GitHub Pages

## Публикация

Публичная витрина публикуется из ветки `main` через GitHub Pages. Настройки и адрес публикации проверяются в **Settings → Pages**.

## Принципы безопасности

- Не публиковать личные сведения без разрешения.
- Не помещать пароли, OAuth Client Secret, access token, refresh token и ключи шифрования в GitHub.
- Не считать подготовленный код работающей интеграцией до развёртывания и проверки.
- Сохранять единое информационное ядро и не создавать параллельные семейные базы без отдельного архитектурного решения.

Старая локальная версия KOMAROVA_CORE не изменяется и не является частью этого репозитория.
