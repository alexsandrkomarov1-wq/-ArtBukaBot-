# KOMAROVA_CORE

Публичная витрина семейного проекта KOMAROVA_CORE.

## Назначение

KOMAROVA_CORE — проект единого семейного информационного пространства: семейная история, открытые материалы, события и публичные публикации.

Эта версия предназначена только для публичной информации. Личные данные, контакты, документы, переписки и закрытые семейные сведения сюда не загружаются.

## Архитектурные принципы

- [Технологическая эволюция и ресурсная эффективность](docs/technology-evolution-resource-efficiency.md) — обязательный принцип развития без необоснованного роста требований к ранее поддерживаемому оборудованию.

## Технологии

- Jekyll
- Markdown и Liquid
- GitHub Pages

## Публикация

В настройках репозитория откройте **Settings → Pages** и выберите:
- Build and deployment: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

После сохранения GitHub Pages соберёт сайт. Адрес появится в разделе Settings → Pages.

## Статус

Начальная публичная версия. Разделы и материалы будут добавляться после проверки и отдельного согласования.

Старая локальная версия KOMAROVA_CORE не изменяется и не является частью этого репозитория.
