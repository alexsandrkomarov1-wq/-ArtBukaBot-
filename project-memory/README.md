# KOMAROVA_CORE — постоянная память проекта

Эта папка хранит подтверждённый контекст разработки KOMAROVA_CORE между сессиями: текущее состояние, решения, ограничения и карту структуры.

- [Текущее состояние](PROJECT_STATE.md)
- [Журнал решений](DECISIONS.md)
- Правила папок и памяти: [docs/PROJECT_FOLDER_AND_MEMORY_POLICY.md](../docs/PROJECT_FOLDER_AND_MEMORY_POLICY.md)

## Правила
- Обновлять после каждого существенного изменения.
- Отделять подтверждённые факты от планов и предположений.
- Ссылаться на коммиты, CI и документы-доказательства.
- Не хранить здесь семейные оригиналы, персональные документы, OAuth-токены, пароли и API-ключи.
- Не смешивать память второго проекта с этой папкой.
