# KOMAROVA_CORE — журнал решений

Новые решения добавлять в конец с датой, автором/источником и ссылкой на документ или коммит. Не удалять старые записи; отмену решения фиксировать отдельной записью.

## 2026-11-27 — постоянная память внутри проекта
- Решение: проектная память хранится в `project-memory/` внутри репозитория/рабочего пространства самого проекта.
- Причина: контекст должен переживать завершение чата и быть доступен следующему рабочему циклу агента.
- Ограничение: не хранить семейные приватные материалы и секреты в публичном репозитории.
- Доказательство: `docs/PROJECT_FOLDER_AND_MEMORY_POLICY.md`.

## 2026-11-27 — папки добавляются по утверждённому правилу
- Решение: новые папки сначала предлагаются с назначением, оценкой размера, доступа и резервирования; затем утверждаются владельцем и только после этого создаются.
- Не создавать заранее пустые каталоги на все гипотетические функции.
- Доказательство: `docs/PROJECT_FOLDER_AND_MEMORY_POLICY.md`.

## 2026-11-27 — два проекта не смешиваются
- Решение: оба проекта используют одинаковый стандарт папок и интерфейса, но имеют отдельные project-memory, журналы, данные, права и резервные копии.
- Проект 2 не идентифицирован. До указания точного имени/репозитория не создавать для него папки и не предполагать его структуру.
