# KOMAROVA_CORE Desktop

Локальный MVP настольного приложения Windows.

## Реализовано в версии 0.1.0
- выбор папки через системный диалог Windows;
- рекурсивное чтение выбранной папки и вложенных каталогов;
- фильтрация фото, видео, аудио и документов;
- пропуск символических ссылок;
- выбор локального каталога архива;
- SHA-256 оригинала и повторная проверка скопированного файла;
- дедупликация по SHA-256;
- сохранение в KOMAROVA_CORE_ARCHIVE/objects/ и manifest.json;
- исходные файлы не перемещаются и не удаляются;
- локальная обработка без отправки файлов в интернет.

## Сборка Windows
Требуется Node.js 20+:
~~~cmd
cd desktop
npm install
npm start
npm run dist:win
~~~

GitHub Actions собирает Windows x64 NSIS installer и публикует его как workflow artifact. Это не означает автоматическую установку на ПК пользователя.

## Ограничения
Это локальный каталогизатор, не облачная медиатека. Пока нет учётных записей, защищённого backend, антивирусного карантина, ИИ-анализа фото, OCR, распознавания речи, транскодирования, синхронизации или привязки к PERSON-ID. Поле ownerPersonId остаётся пустым. Не используйте публичный репозиторий для семейных файлов и реального manifest.json.
