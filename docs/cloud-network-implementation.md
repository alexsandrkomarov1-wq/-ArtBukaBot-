## Цель

Объединить основной портал KOMAROVA_CORE и раздел AI MEDIA в единую систему управления семейным архивом с общим каталогом материалов и поддержкой нескольких облачных провайдеров.

## Обязательные принципы

1. Вся разработка выполняется только в `core-backend-foundation`. Ветка `main` не изменяется.
2. Оба интерфейса используют единый каталог и согласованные API/идентификаторы.
3. Supabase: использовать только существующий проект KOMAROVA_CORE; не создавать новый проект.
4. До отдельного разрешения не менять настройки, пароль, таблицы, Storage и функции Supabase.
5. Google Drive считать временным подключением до получения ожидаемого ответа; не объявлять его постоянным провайдером.
6. Air Live Drive — необязательный Windows-клиент для доступа к облакам, а не серверный механизм синхронизации.
7. Подключение облаков на сайте выполнять через отдельные серверные адаптеры/API и защищённое хранение OAuth-секретов. Секреты и service-role ключи не помещать в браузер или Git.
8. Оригиналы неизменяемы. Производные/улучшенные файлы получают отдельный MATERIAL-ID и ссылку на исходный материал.
9. Для каждой копии вести провайдера, удалённый идентификатор, состояние синхронизации, размер и SHA-256. Проверять результат чтением и контрольной суммой.
10. Ошибка или отключение одного провайдера не должны останавливать остальные и не должны разрушать каталог.
11. Не выполнять массовое перемещение, перезапись или удаление файлов. Предусмотреть повтор синхронизации, журнал ошибок, экспорт и восстановление.
12. Не считать функцию готовой без проверки реального сценария записи, чтения, проверки целостности и отказа провайдера.

## Модель аккаунтов членов семьи

Для каждого члена семьи допускается отдельное подключение каждого провайдера. Реестр подключения должен содержать как минимум `person_id`, `provider`, `provider_account_id`, `remote_user_id`, `oauth_subject`, зашифрованные токены/ссылку на секрет, разрешённые scopes, статус, время последней проверки и журнал ошибок. Один и тот же провайдер может иметь много подключений; нельзя хранить один общий токен на всю семью или подменять аккаунт одного человека другим. Два Google Drive окна являются двумя отдельными подключениями, но не ограничивают число аккаунтов. Статус `connected` устанавливается только после авторизации конкретного владельца и успешной проверки API. Для AI MEDIA backend получает материал через внутренний API и создаёт производную копию с новым MATERIAL-ID; AI не получает пароли провайдеров.
