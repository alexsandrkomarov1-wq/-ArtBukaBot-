# KOMAROVA_CORE — реестр изменений автономного помощника

**Назначение:** append-only реестр наблюдаемых и выполненных изменений. Этот файл не заменяет Git и журнал активного времени.

## Формат записи

Для каждой записи указывать:
- `CHANGE-ID`;
- UTC timestamp и локальное время `Europe/Amsterdam`;
- actor: `agent`, `owner`, `human-reviewer`, `ci`, `git-observer`;
- task ID;
- тип: `OBSERVED`, `EXECUTED`, `VERIFIED`, `OWNER_REPORTED`, `UNKNOWN`;
- файлы/объекты;
- краткое описание;
- источник доказательства (commit SHA, CI run URL, локальный тестовый отчёт или ручное подтверждение);
- результат и статус проверки.

Нельзя задним числом приписывать изменения агенту. Нельзя считать обнаруженный commit доказательством активного времени. Новые записи добавляются в конец; исправления оформляются отдельной корректирующей записью, исходная запись не удаляется.
