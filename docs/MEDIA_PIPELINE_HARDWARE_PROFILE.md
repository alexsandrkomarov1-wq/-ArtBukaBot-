# KOMAROVA_CORE — медиапроцессинг с учётом имеющегося ПК

**Профиль оборудования:** Windows 10 Pro 64-bit, Intel Core i5-760 (4 ядра / 4 потока, без AVX/AVX2), 8 GB RAM, AMD Radeon HD 5670. Это слабая legacy-система; тяжёлые нейросетевые задачи нельзя делать обязательными для локального ПК.

## 1. Архитектурное решение

Разделить интерфейс и обработку:
- ПК/телефон открывает лёгкий веб-интерфейс KOMAROVA_CORE.
- Локальный ПК выполняет простые операции по требованию и только при достаточном свободном ресурсе.
- Тяжёлые AI-задачи выполняются отдельным удалённым worker только после выбора владельцем подходящего бесплатного/разрешённого ресурса и проверки конфиденциальности. Не отправлять семейные фото/видео внешней модели автоматически.
- Задание создаётся в очереди, получает ID, статус, параметры, источник и отчёт.
- Оригинал неизменяем; результат — новый MATERIAL-ID со ссылкой на оригинал. Ошибка обработки не влияет на оригинал.

## 2. Локальный профиль

- Базовые фотооперации: обрезка, поворот, изменение размера, яркость/контраст/цвет, конвертация и создание копии — Pillow/OpenCV в умеренных размерах.
- Видео: FFmpeg как основной движок для склейки, обрезки, титров/заставки, наложения музыки, громкости, плавных переходов и экспорта.
- Работать с копией/прокси и разрешением SD/низким HD; по умолчанию ограничить параллелизм одним заданием.
- Не выполнять массовую индексацию/распознавание лиц, транскодирование всей библиотеки и AI upscale в фоне.
- Проверить совместимость конкретной сборки FFmpeg с CPU без AVX до установки; не предполагать, что современный бинарный файл запустится.
- Shotcut/Kdenlive могут служить необязательными внешними редакторами, но не должны быть обязательной зависимостью сайта. Их текущие требования для HD начинаются с 8 GB RAM и 4 CPU cores, то есть ПК пользователя находится на нижней границе; для 4K он не подходит.

## 3. AI-функции

- Фото: сначала безопасные классические улучшения; AI-резкость/реставрация/раскраска — отдельная очередь, уменьшенные тайлы и тест на копии. Модель Real-ESRGAN General x4v3 или аналогичный компактный вариант рассматривать только после реального теста на HD 5670/CPU без AVX; скорость и совместимость не гарантировать.
- Видео: локально — монтаж, заставки, музыка, шумоподавление/масштабирование в простом режиме; AI frame generation, тяжёлое увеличение разрешения и генерация кадров — только внешний worker/отдельный сервер после проверки стоимости, приватности и доступности.
- Музыка: использовать только загруженные пользователем или лицензированные/свободные аудиофайлы. Хранить источник и сведения о лицензии; не встраивать коммерческие треки без разрешения.
- Истории: ИИ может составлять сценарий/подписи из подтверждённых событий и выбранных материалов. Он не должен выдавать выдуманные факты за семейную историю.

## 4. Референсы и что заимствуем

- Immich: временная шкала, карта, альбомы, мобильная загрузка, поиск и «воспоминания N лет назад». Для слабого сервера ML можно отключать или выносить отдельно.
- Nextcloud Calendar: отдельный календарь дней рождения на основе дат в контактах.
- Candlr: повторяющиеся даты, неизвестный год рождения, напоминания, импорт/экспорт и приватная iCalendar-подписка.
- Shotcut/Kdenlive: монтаж с proxy/preview scaling, но только как ориентир UX; не как обязательная часть KOMAROVA_CORE.

## 5. Критерии приёмки

- Интерфейс не блокируется во время обработки.
- Очередь показывает ожидание, обработку, проверку, готовность и ошибку.
- До/после показываются рядом; экспорт создаёт новый материал.
- Локальные задачи автоматически ограничивают CPU/RAM и поддерживают отмену.
- Видеомастер умеет собрать слайд-шоу, титульную заставку, музыку с регулировкой громкости и финальные титры на копии.
- AI-функции помечаются по фактическому месту выполнения: LOCAL, REMOTE или NOT_CONNECTED.
- Нет обещаний реального AI-улучшения до успешного теста на конкретном оборудовании.
